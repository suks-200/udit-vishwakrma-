# Vishwarkrma — Creative Designer Portfolio

A dependency-free, responsive portfolio website built with semantic HTML, modern CSS, and vanilla JavaScript.

## Run locally

From the project directory:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Features

- Dark/light themes with saved preference
- Responsive editorial masonry gallery
- Category filters
- Full-screen project viewer with zoom and keyboard navigation
- Custom cursor and parallax effects
- Mobile menu and reduced-motion support
- Local project enquiry form with no external data collection
- All 37 repository images are referenced from the local `photos` directory

## Asset notes

The portfolio uses only assets present in `photos/`. Project titles for generic WhatsApp captures are intentionally neutral and do not claim a client, date, or project outcome.
